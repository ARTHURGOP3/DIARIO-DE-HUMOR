## Study Context

> This project introduces a web application focused on mental health and self-care, developed as a **Capstone Project (TCC)** for the Systems Development program at ETEC. It demonstrates how to apply programming concepts to solve real-world problems, directly supporting the **UN's Sustainable Development Goal 3 (Good Health and Well-being)** by encouraging emotional self-awareness. Project management utilizes agile methodologies (Scrum) and Project Model Canvas for optimal planning and execution.

<br/>

## The Application

A dynamic mood tracking system that allows users to securely log their daily emotional states. The application registers the user's mood, contextual tags (such as sleep, work, or family), and generates a visual dashboard. It also features a static support page with public emergency contacts (e.g., CVV 188) and an option to export the mood history as a PDF for psychological therapeutic follow-up.

<br/>

## Business Rules (Applied Logic)

1. **Privacy & Security:** Sensitive user data and mood logs are strictly isolated and protected via user authentication. 
2. **Contextual Pattern Recognition:** Moods are directly linked to selected tags, allowing the dashboard logic to generate correlations (e.g., how sleep affects the user's weekly mood).
3. **Automated Report Generation:** The system processes historical data dynamically to assemble a downloadable PDF summarizing the patient's emotional timeline.

<br/>

## How to Run (Local Deploy)

1. Clone this repository or download the files.
2. Ensure you have a local Apache server environment configured (e.g., XAMPP, WAMP).
3. Move the project folder to your local server root (e.g., `htdocs` for XAMPP).
4. Open a web browser and access the application via `http://localhost/[project_folder]/index.php`.

## Contexto do Estudo

> Este projeto apresenta uma aplicação web focada em saúde mental e autocuidado, desenvolvida como **Trabalho de Conclusão de Curso (TCC)** para o curso de Desenvolvimento de Sistemas da ETEC. Ele demonstra como aplicar conceitos de programação para resolver problemas reais, apoiando diretamente o **Objetivo de Desenvolvimento Sustentável 3 da ONU (Saúde e Bem-estar)** ao incentivar o autoconhecimento emocional. O gerenciamento do projeto utiliza metodologias ágeis (Scrum) e Project Model Canvas para otimizar o planejamento e a execução.

<br/>

## A Aplicação

Um sistema dinâmico de rastreamento de humor que permite aos usuários registrar seus estados emocionais diários de forma segura. A aplicação grava o humor do usuário, tags contextuais (como sono, trabalho ou família) e gera um dashboard visual. Também conta com uma página de apoio estática com contatos de emergência pública (ex: CVV 188) e uma opção para exportar o histórico em PDF para acompanhamento terapêutico.

<br/>

## Regras de Negócio (Lógica Aplicada)

1. **Privacidade e Segurança:** Dados sensíveis e registros de humor são estritamente isolados e protegidos por meio de autenticação de usuário.
2. **Reconhecimento de Padrões Contextuais:** Os humores são vinculados às tags selecionadas, permitindo que a lógica do dashboard gere correlações (ex: como o sono afeta o humor semanal do usuário).
3. **Geração Automatizada de Relatórios:** O sistema processa dados históricos dinamicamente para montar um PDF para download, resumindo a linha do tempo emocional do paciente.

<br/>

## Como Executar (Deploy Local)

1. Faça o clone deste repositório ou o download dos arquivos.
2. Certifique-se de ter um ambiente de servidor Apache local configurado (ex: XAMPP, WAMP).
3. Mova a pasta do projeto para a raiz do seu servidor local (ex: `htdocs` no XAMPP).
4. Abra um navegador web e acesse a aplicação via `http://localhost/[pasta_do_projeto]/index.php`.
